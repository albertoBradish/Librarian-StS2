# Contributing / 参与反馈

Bug reports, balance observations, translation fixes and reproducible small PRs
are welcome. Search existing issues first. Include exact versions and the source
commit when relevant; follow the issue forms for reproducibility details.

Run the pure rule suite documented in [BUILDING.md](BUILDING.md) for rule changes.
For native integration changes, describe the actual environment and validation
scope. Do not equate successful compilation with game runtime or multiplayer tests.
Keep existing asset mappings and card rules intact unless the change is intentional.

Before submitting code, request the maintainer's written permission for the proposed
adaptation/contribution in an issue. This repository does not grant blanket permission
to publish modified versions. Agreed contributions must be compatible with the
project's custom LICENSE, preserving upstream licenses. Only contribute work you
can license. Third-party assets require explicit provenance
and compatible permission; do not upload extracted game resources or decompiled
game source, dependency binaries, private logs, credentials or save files.

Original setting, text and visual media follow [ASSET-LICENSE.md](ASSET-LICENSE.md); permission for personal source study/builds
does not grant adaptation, redistribution or artwork reuse. Translation packs are described in
[TRANSLATIONS.md](TRANSLATIONS.md).
